# 语言服务

桌面版在「设置 → 语言服务」中提供插件市场。搜索语言或发布者，点击「安装」后会从官方 npm、NuGet、GitHub Releases 或 Eclipse 下载服务器。安装在 MDE 的本机应用数据目录，不需要把语言服务器安装到全局 PATH。

「已安装」页面可以查看插件详情、启用/禁用、重启服务以及卸载。卸载先停止该插件的语言服务进程，再删除它在 MDE 中的安装目录；不会删除语言运行环境和项目文件。安装过程支持进度、取消、失败日志和重新安装。

插件语言的补全、悬浮说明、跳转和诊断由插件统一提供，Monaco 自带的 JavaScript/TypeScript、HTML、CSS 语言服务不会绕过插件开关。禁用或卸载时立即解除编辑器绑定，取消未完成的请求并清空该插件的诊断；语法高亮和 Ctrl+点击外部链接继续可用。卸载失败会显示实际错误并恢复可用服务，不会显示卸载成功。

| 插件 | 本机运行环境 |
| --- | --- |
| JavaScript / TypeScript、HTML、CSS、Python Pyright | Node.js 和 npm |
| C# Roslyn | .NET 10 SDK 或更新版本 |
| Kotlin | JDK 17–21，自动选择兼容版本，避免 JDK 25 与服务器内置编译器不兼容 |
| Java Eclipse JDT | JDK 21 或更新版本 |
| Rust rust-analyzer | Rust 工具链；标准库分析需要 rust-src |

安装和服务连接是两个状态。打开对应文件后才启动服务。连接失败会显示实际错误，可以在插件详情查看日志。服务器接受当前编辑缓冲区，提供补全、悬浮说明、定义跳转、引用、诊断和格式化，具体能力取决于服务器。

Kotlin 独立文件会加载语言服务器附带的配套标准库，让 `Unit`、`println`、`kotlin.random.Random` 等基础 API 正常解析。依赖配置仅作用于当前服务进程，服务退出时自动清理；Maven/Gradle 项目和用户自定义 classpath 继续使用项目自己的依赖。

Rust 的 Cargo 项目按 Cargo.toml 识别；独立 `.rs` 文件自动生成内存中的工程描述并关联标准库源码，不把源码路径当成工程清单，也不改写用户项目文件。独立文件需要 `rustup component add rust-src`；缺少时会显示明确错误。服务器完成工程加载后会自动刷新诊断。

## 添加语言

点击搜索栏旁的「+」，可以添加 HTTPS 插件目录地址，或粘贴单个插件的 JSON 清单。目录返回清单数组。语言和扩展名由清单贡献，编辑器无须增加硬编码列表。

例如添加 Bash：

```json
{
  "id": "community.bash",
  "name": "Bash Language Server",
  "publisher": "Community",
  "version": "latest",
  "description": "Shell language intelligence",
  "languages": ["shell"],
  "extensions": { "sh": "shell" },
  "args": ["start"],
  "install": {
    "kind": "npm",
    "packages": ["bash-language-server"],
    "executable": "bash-language-server"
  }
}
```

支持 npm、dotnet、github、archive 和 jdtls 安装方式。archive 可指定 HTTPS 下载地址、压缩格式、相对可执行文件路径和 SHA-256；github 可指定仓库及发布附件名称。完整字段示例见 `src/configs/language-plugins.json`。同一语言启用多个服务时，可以在详情中选择默认服务。

## 编辑器交互

底部工具窗口栏可切换「输出」和「问题」。问题页显示当前文件的错误、警告、弱警告和提示，包含行号与列号，支持级别和文本筛选。双击问题或按 Enter 跳转并选中对应代码。Ctrl+Shift+M 打开问题页，Ctrl+J 展开/收起工具窗口；切换文件不会清空运行输出。

Monaco、Markdown 分栏预览和所见即所得均支持 Ctrl+滚轮改变内容字号。分栏关闭「同步缩放」后，两侧字号独立；同步缩放时一并改变。Ctrl+点击外部链接会交给系统浏览器，本地 Markdown 相对链接继续由应用内文件导航处理。
