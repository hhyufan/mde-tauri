# MokiDown 启动动画 · 视觉规格（交付画图 AI）

> 这份文档是给图像生成用的**设计任务书**。目标是产出一段「启动动画」所需的整套视觉素材：
> 应用启动时先弹出欢迎动画（期间在后台初始化），动画结束后淡出、露出编辑器本体。
> 参照 IntelliJ IDEA 的 splash 节奏，但视觉语言必须来自 **Moki 吉祥物 Logo**。

---

## 一、任务与使用场景

| 项 | 说明 |
|---|---|
| 用途 | 桌面应用（Tauri + WebView2，Windows 为主）启动时的过渡动画 |
| 时长 | 2.5–3.0 s（含停留），结束后淡出 0.4 s |
| 关键约束 | **动画期间在后台初始化编辑器**。它是「遮罩 + 情绪」，不是进度条；禁止百分比数字 |
| 气质 | 可爱、干净、轻快、有秩序感；**不要**商务感、不要科技蓝光、不要 3D 渲染感 |
| 画面性质 | 手绘扁平插画（和 Logo 同一笔触），不是写实、不是渐变网格 |

## 二、视觉语言（从 Logo 提取，必须延续）

来源素材：`src/assets/characters/可爱星际 Moki 吉祥物Logo.png`（1672×941）

### 2.1 关键特征（务必保留）

1. **手绘圆体字标**：`Moki` 为圆润泡泡体、笔画粗、外描边深蓝、内填白色
2. **「o」是一个蓝色圆球**，球心嵌白色四角星
3. **「i」的点是一枚蓝色小方块**，方块内是白色字母 M
4. **装饰元素**：黄色五角星 / 蓝色四角星 / 黄色速度线（小短弧）
5. **浅蓝水彩光晕**：字标下方一圈柔和不规则晕染（不是硬边椭圆）
6. **角色姿态**：托腮闭眼笑（亲和），头戴 **M 形发饰**（右竖收成下箭头），穿蓝白校园制服，手边有笔记本

### 2.2 笔触规则

- 所有形状**外描边深蓝 `#1B3A8C`**，线宽统一（约为元素短边的 3–4%）
- 白色填充带**轻微手绘抖动**，不做几何完美直线
- 阴影只用**同色系深蓝的柔和投影**，禁止灰黑投影
- 允许 1–2 处**溢出画面的小元素**（小星星被边缘裁切），增加活泼感

## 三、色板（精确值，请严格使用）

### 浅色主题（默认出图）

| 用途 | 色值 |
|---|---|
| 画面底色 | `#F5F5F7`（可加同色系更浅晕染 `#FBFDFF`） |
| 卡片/面板 | `#FFFFFF` |
| 主品牌蓝 | `#4091FF` |
| 深蓝描边 | `#1B3A8C` / 角色服装深色 `#243653` |
| 强调黄 | `#FFD24A`（星星）/ `#F5C13D`（深一档） |
| 主文字 | `#2C2C2E` |
| 次级文字 | `#6D6D6F` |
| 弱化文字/占位 | `#C4C4C6` |
| 浅蓝水彩 | `#E7EFFF` → `#DBE8FF` → `#F2F7FF` |

### 深色主题（需要第二版）

| 用途 | 色值 |
|---|---|
| 画面底色 | `#121212` |
| 卡片/面板 | `#1E1E1E` |
| 主品牌蓝 | `#5A9FFF`（比浅色亮一档） |
| 深蓝描边 | 角色深色服装 `#16233A` / `#1C293F` |
| 主文字 | `#F5F5F7` |
| 次级文字 | `#98989D` |

> 深色版**不要**把浅色图直接反相。规则：底色变暗、蓝色提亮、黄色保持饱和度、水彩光晕改成低透明度蓝色发光。

## 四、画布与布局

### 4.1 主画面（必需）

| 项 | 规格 |
|---|---|
| 尺寸 | **1600 × 1000 px**（@1x 交付，另出 2x） |
| 比例 | 16:10 |
| 出血 | 四周留 40px 安全边距，装饰元素可溢出但主体不出安全区 |

### 4.2 构图（横版，左文右图）

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│   ✦(黄)                                     ✦(蓝)    │
│                                                      │
│   ┌── 字标区（手绘圆体）──┐         ╭──────────╮      │
│   │   M o k i            │         │  Moki 角色 │      │
│   │   ↑o=蓝球+四角星      │         │  托腮闭眼笑 │      │
│   │   ↑i=蓝方块+M        │         │  半身      │      │
│   └──────────────────────┘         ╰──────────╯      │
│          ～～水彩光晕～～              ↑             │
│                                      笔记本/星星      │
│   MokiDown                            (点缀)          │
│   Markdown 编辑器                                     │
│                                                      │
│   ● 正在准备你的工作区…                                │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**层级（从后到前）**

1. 底色 + 浅蓝水彩光晕（最大，柔边）
2. 装饰：黄色五角星 ×2–3、蓝色四角星 ×2–3、黄色速度线 ×3–4
3. 角色 Moki（右侧，占画面高度约 **62–70%**）
4. 手绘字标 `Moki`（左上，宽度约占画面 **34%**）
5. 产品名 `MokiDown` + 副标题 `Markdown 编辑器`（字标下方，常规体，非手绘）
6. 状态行（左下，带一个呼吸小圆点）

### 4.3 文案（必须用这些原文，不要改写）

| 位置 | 中文 | 英文 |
|---|---|---|
| 字标 | `Moki` | `Moki` |
| 产品名 | `MokiDown` | `MokiDown` |
| 副标题 | `Markdown 编辑器` | `Markdown Editor` |
| 状态行 | `正在准备你的工作区…` | `Preparing your workspace…` |

> 状态行是**唯一的进度指示**，只用一个缓慢呼吸的圆点（品牌蓝），**不要**进度条、不要百分比。

## 六、动画序列（6 帧故事板）

需要交付**关键帧**，而不是每帧动画。建议按下列节奏出 6 张：

| 帧 | 时间 | 画面 | 要点 |
|---|---|---|---|
| F1 | 0.00s | 只有水彩光晕在扩散 + 1 颗小星 | 底色已铺满，画面很空 |
| F2 | 0.25s | 字标 `Moki` 逐字弹出（`M`→`o`→`k`→`i`） | 字母带轻微过冲回弹，`o` 的球与 `i` 的方块最后落定 |
| F3 | 0.55s | 角色从右侧滑入 + 星星依次点亮 | 角色可带一点点倾斜进入 |
| F4 | 0.80s | 产品名与副标题淡入上移 | 常规体，不与字标争视觉 |
| F5 | 1.60s | 完整稳定态（停留） | 状态行呼吸中；这是**主交付帧** |
| F6 | 2.90s | 整体淡出（透明度下降 + 轻微放大 1.02） | 露出下方编辑器 |

**F5 是必须精修的主帧**；其余帧允许粗略，用于说明运动方向。

## 七、交付清单

请按**分层**导出，便于工程用 CSS/JS 还原动画（切勿只给一张合成图）：

1. `bg-light.png` / `bg-dark.png` —— 底色 + 水彩光晕（1600×1000，可无缝平铺）
2. `wordmark-moki.png` —— 手绘字标，**透明背景**，含 `o` 的球与 `i` 的方块
3. `moki-hero.png` —— 角色立绘，透明背景，**浅色服装版**
4. `moki-hero-dark.png` —— 角色立绘，透明背景，**深色服装版**（夜读感）
5. `decor-stars.png` —— 星星与速度线，透明背景，元素**彼此分离**便于单独运动
6. `frame-01…frame-06.png` —— 上面 6 张关键帧（可含完整画面）
7. **可选**：`badge-moki.png` —— 圆形徽章版（用于左上角 32px 标识，构图要能在极小尺寸下辨认）

**导出规格**：PNG-24 透明背景；主帧另出 @2x；单文件建议 < 400KB；文字若需可编辑请额外给分层 PSD/ASE。

## 八、容易漏掉的补充项（请一并考虑）

1. **深色主题整套**：底色/描边/文字都要另一版，不能反相
2. **极简版（无角色）**：设置里可关闭 Moki 形象。需要一张**只有字标 + 光晕**的版本
3. **固定尺寸下的裁切**：splash 窗口可能只有 480×320，请同时给一张**紧凑构图**（字标上、角色下、去掉状态行）
4. **超宽屏**：编辑器本体可能全宽，splash 需要能在 3440px 宽度下居中不空
5. **`prefers-reduced-motion`**：需一张**静态定格图**（直接用 F5），供禁用动画时显示
6. **徽章化**：`Moki` 字标要能在 32px 下辨认（建议另出一版简化为「蓝球 + 四角星」，去掉字）
7. **失败态**：若初始化异常，同一构图把状态行与圆点换成错误色（`#FF3B30`）并给一张变体
8. **多语言**：英文版文案更长（`Preparing your workspace…`），排版需预留宽度
9. **切图命名与图层顺序**要标注清楚，工程按「光晕 → 装饰 → 角色 → 字标 → 文字 → 状态行」叠放

---

## 九、明确不要做的事

- 不要进度条、百分比、加载圈（spinner）
- 不要 3D、玻璃拟态、霓虹光、粒子爆炸等科技风元素
- 不要把应用图标（蓝色圆 + 白 M）当作主视觉——那是**备选标识**，主视觉是 Moki 角色与手绘字标
- 不要写实人脸/写实发丝，保持 Logo 的手绘扁平感
- 不要改变角色设定：蓝发、M 形发饰、蓝白制服、笔记本

## 十、工程侧交接说明

- 动画结束后淡出，露出的是编辑器本体；欢迎页（`moki-welcome`）与 splash **不冲突**，先 splash 后欢迎页
- 角色素材现已有双格图集 `moki-day-night-bust.png`（浅色挥手 / 深色托腮），本次新画的立绘建议**与它风格对齐**，避免同一角色两套笔触
- 若质量达标，后续可把 `badge-moki.png` 用于左上角 32px 标识，替代当前的圆形徽章
